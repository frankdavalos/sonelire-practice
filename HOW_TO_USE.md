# How to use Sonelire Practice

**A parent and caregiver guide · Version 2**

[Open Sonelire Practice](https://frankdavalos.github.io/sonelire-practice/sonelire-practice.html) · [Project README](README.md)

Sonelire Practice is a simple way to help a child learn the letters of the alphabet and the sounds they represent. An adult asks questions, models correct answers during practice, and records responses during occasional letter checks. The website does not listen to the child or play audio.


## New in v2.1: use your phone as the scoring sheet

You can use the digital companion instead of paper. The child sees the letter on the iPad, while you record responses privately on a phone. Both devices need access to the hosted site. No account is required.

1. On the iPad select the learner, **Assess**, the skill, case and order, then **Prepare check**.
2. Select **Phone companion QR**. On your phone, open the Camera app and scan the QR code. Open the link. Confirm the form ID and first letter.
3. Select **Begin check** on the iPad. Ask the child to name the letter or produce the chosen familiar sound. Do not reveal the answer.
4. Check that the item on your phone matches the iPad letter. Tap **Correct**, **Incorrect**, **Unsure / no response**, or **Skip** on the phone. The phone advances automatically except at the final item; tap the iPad separately to advance its letter.
5. If the devices become out of step, use **Previous**, **Next**, or the numbered item grid on your phone to realign them. Use **Clear this mark** or **Undo last change** to correct an entry. Marks and position are saved locally on the phone when storage is available. Undo history is not retained after reload.
6. When the presentation is complete, advance from the last letter on the iPad to **Enter results**. If stopping early, pause and end presentation; leave unreached letters unmarked on the phone.
7. On the phone choose **Prepare results transfer**. You can return to edit any marks before transferring.
8. Return the marks using one of these options:
   - **QR:** Open the iPad Camera, scan the phone's results QR and open the link in the same browser context as your unfinished check. QR links open only in Safari, so this does not work when the check runs in the Home Screen app. The app opens **Enter results** with the code ready for review.
   - **Code:** Copy the code and transfer it privately (for example with a shared clipboard, if configured). On the original iPad scoring screen expand **Import phone companion results** and paste it into the text box.
   - **File:** Choose **Save code file** on the phone, transfer the small text file privately, then select **Choose code file** in the iPad import panel.
   - **Share:** If the phone can share files, choose **Share results** and AirDrop the text file to the iPad, then select **Choose code file** in the iPad import panel. Use this when the check runs in the Home Screen app, which QR links can't reach (see [Install on the iPad Home Screen](#install-on-the-ipad-home-screen-recommended)).
9. Select **Review and import marks**. Sonelire checks the form, order and response count, rejecting wrong-form codes or marks for letters not shown. If replacing conflicting entries, confirm only if intended. Review the populated marks, then select **Save results**.
10. Use the **Practice** button on **Results** as before. Once the results are saved on the iPad, clear the companion record on your phone using **Clear this companion session**.

**Important:** The two devices do not advance each other. Results codes and QR links are not encrypted. Treat them as private. Avoid sharing them in public messages. The phone companion does not identify the learner; the iPad attaches the validated marks to its own existing session.

If the iPad Camera opens a browser without your draft, return to the original browser and paste the code or import the text file (for example with **Share results**) instead. The Home Screen app and Safari have separate storage, so a check started in one cannot be finished in the other. If the companion is interrupted, scan the original QR again (the paused iPad screen has **Show phone companion QR again**). If local storage is unavailable, keep the phone page open. You can always use manual scoring or a paper companion sheet.


## 1. Get started

Open the website on an iPad, phone or computer. Choose **Child 1** or **Child 2** from the **Learner** menu at the top of the screen. Use the same profile for each child every time, so their results remain separate.

There are three main tabs:

| Tab | When to use it |
| --- | --- |
| **Practice** | Teach and review letters together. |
| **Assess** | Find out what your child can identify independently. |
| **Results** | Review which letters are known and which need additional practice. |

On a phone or computer, use the website in your usual browser and keep to the same one. On an iPad, install it to the Home Screen as described next.

### Install on the iPad Home Screen (recommended)

Safari can delete a website's saved data after 7 days of use without opening that site. An app on the Home Screen keeps its own count, and Sonelire Practice asks the iPad to keep its data each time it opens, so results are much less likely to disappear. Neither is a guarantee, so keep backups as well (see the end of this section).

1. Open the website in Safari on the iPad.
2. Tap *Share*, then *Add to Home Screen*, then *Add*.
3. Open the Sonelire icon on the Home Screen. It opens full screen, without Safari's address bar, but still needs an internet connection. Use it from there from now on.

The Home Screen app is a separate copy, with its own storage. Results and checks saved in Safari do not appear in it, and anything saved in it does not appear in Safari.

**Move existing results in:** if you already used the website in Safari, bring those results across with a Backup file.

1. In Safari, finish any unfinished check first: it is not in the Backup file. Then open **Results** and select **Export backup**. Save the Backup file to iCloud Drive or Files.
2. In the Home Screen app, open **Results**, select **Restore from backup** and choose that file. Read the preview, then confirm. Restoring replaces the saved results and checks of both learners in the Home Screen app, and keeps any unfinished check there.

**Get phone results back:** results QR links open only in Safari, never in the Home Screen app, so the iPad Camera cannot hand the phone's marks to a check running in the Home Screen app. Send a file instead:

1. On the phone, choose **Prepare results transfer**, then **Share results** and AirDrop the text file to the iPad (or save it to iCloud Drive or Files).
2. On the iPad's **Enter results** screen, expand **Import phone companion results**, select **Choose code file** and pick the file.
3. Select **Review and import marks**, review the marks, then select **Save results**.

If the phone cannot share files, use **Save code file** and move the file another way, or copy the code and paste it into the same panel.

**Keep backups:** export a fresh Backup file to iCloud Drive regularly, for example after each check or once a week. It is the only copy that survives if the iPad clears the app's data or the app is removed from the Home Screen. If a saved check has gone more than 30 days without a backup, the **Results** tab shows a reminder until you export one.

## 2. Practice letters together

Open **Practice** and select the options that fit your child's needs.

| Option | What it does |
| --- | --- |
| **ABC** | Displays uppercase letters (26 cards). |
| **abc** | Displays lowercase letters (26 cards). |
| **Aa mixed** | Displays uppercase and lowercase forms as separate cards (52 cards). |
| **Names** | Reminds the adult to ask for or model the letter name. |
| **Sounds** | Reminds the adult to ask for or model a familiar letter sound. |
| **All letters** | Reviews the entire selected alphabet deck. |
| **Needs practice** | Shows only letters marked incorrect or unsure for this learner, case and skill. |
| **Shuffle** | Switches between randomized order (on) and alphabetical order (off), with uppercase and lowercase paired when mixed. |
| **Focus mode** | Hides the main controls and enlarges the letter; use **Exit focus** to return. |

Use **Previous**, **Next**, or **Start over**. Swipe left to advance and right to go back. In Focus mode, tap the card to advance. On a computer, use the left/right arrow keys or Space to navigate; Escape exits Focus mode. At the end of a practice deck, the next action begins another round.

### What to say during practice

**Letter names:** Show `m` and ask, “What letter is this?” If needed, say, “This is the letter M. Can you say M?”

**Letter sounds:** Show `m` and ask, “What sound can this letter make?” If needed, model the /m/ sound (as at the beginning of *map*) without adding an extra vowel, then invite the child to repeat it.

Names and sounds are different skills. A child may know the name of a letter without knowing its sound. The website changes the practice prompt and selects the relevant saved results, but the adult provides all spoken instructions and sound models.

## 3. Conduct a letter check

A letter check is different from practice. Its purpose is to see what the child can do independently, without hints or correctness feedback.

### Prepare the check

1. Confirm the correct **Learner** is selected.
2. Open **Assess**.
3. Choose **Letter names** or **Letter sounds**.
4. Choose **ABC**, **abc**, or **Aa mixed**. Consider starting with one case at a time to keep the check short.
5. Choose **Shuffled** or **Alphabetical**. Shuffled order is useful for checking recognition rather than memorized alphabet sequence.
6. Select **Prepare check**. The website displays the exact letter order and a form ID.
7. Select **Print companion sheet**, or copy the displayed letters onto paper in the same order. Use one recording row per letter. Keep the sheet out of the child's view.
8. Select **Begin check** when ready.

Do not prepare another check or change the options after recording the letter order: that could produce a different sequence. The prepared form is saved as an unfinished check when you begin, not merely when you prepare it.

### Present the letters and record answers

The child-facing screen displays one large letter at a time, with a small **Pause** control. No scoring buttons, answers or correctness feedback appear.

For a letter-name check, ask “What letter is this?” For a letter-sound check, ask for a familiar sound associated with the letter. Decide which sound or sounds you will accept beforehand, particularly for letters that have several sounds (for example, C or G). There is no built-in answer key or automated pronunciation scoring.

Record the response privately on the companion sheet. Tap the screen or swipe left to advance only after the child has had a chance to respond. Swipe right or press the left arrow to revisit a letter if navigation was accidental; do not use repeated attempts to inflate scores. On a keyboard, the right arrow or Space advances, and Escape pauses.

| Paper mark | Scoring button | When to use it |
| --- | --- | --- |
| **C** | Correct | The child gives an independently correct response. |
| **I** | Incorrect | The child gives an incorrect response. |
| **N** | Unsure | The child is unsure or does not respond. |
| **S** | Skip | The letter was not actually assessed (for example, you accidentally advanced). |

Allow a reasonable, consistent opportunity to respond. Do not teach the answer during the check. If your child is tired or frustrated, pause or stop and return another time. A check is not a race.

### Pause or finish early

Choose **Pause** to stop temporarily. **Resume presentation** returns to the same letter. If you need to stop the check, choose **End presentation and enter scores**. Any letter not yet displayed is automatically excluded; mark displayed but unassessed items as **Skip**.

## 4. Enter and save the results

After the last card (or after ending early), the website opens **Enter results**. Keep this screen out of the child's view.

1. Confirm the learner, skill, case and form ID match the companion sheet.
2. Copy each mark to the matching letter row using **Correct**, **Incorrect**, **Unsure**, or **Skip**. On a keyboard, focus a row and press C, I, N or S to enter the mark and move to the next displayed row.
3. To save time, you may enter every exception first and use **Mark remaining as correct** only if the paper sheet confirms all remaining displayed letters were independently correct. Confirm the bulk action when prompted.
4. Review each mark. Select another scoring button on a row to correct an entry. **Clear marks** resets all entries in the unfinished check, after confirmation.
5. Select **Save results**. The button becomes available when every displayed letter has a mark.

If you cannot finish entering results, choose **Finish later** and keep the paper sheet. The **Resume check** notice lets you return to the unfinished check. Only one unfinished check can be stored across both learner profiles. **Discard** removes that draft after confirmation, but retains previously saved results.

## 5. Understand the results

Open **Results** and select the case and skill you want to review. **At a glance** sums up the selected child's letters:

- A ring shows how many letters are correct, out of all the letters in the selected case. Next to it, one line compares that with the previous check ("2 more letters correct · compared with …", "Same as …" or "1 fewer letter correct than …"). After the first check it says **First check** instead. Below that, it counts the letters that need practice and the letters not checked yet. Before any check for these letters it says **No checks yet for these letters.** and offers **Check these letters**.
- Short lines name the letters that changed in the latest check, compared with just before it:
  - **Recent wins:** correct now, after being incorrect or unsure.
  - **Slipped back:** incorrect or unsure now, after being correct.
  - **Still learning:** every other letter that needs practice, including one checked for the first time.

  A line with no letters is left out. Skipped letters never change a letter's line.
- The **Practice** button names the letters that need practice, for example "Practice B, D, H →", or gives their number when there are more than five.

The letter grid shows the latest recorded status for each selected letter and the date it was last checked. Letters that were never checked, or only skipped, say Not checked yet and show no date. An ↑ marks a recent win and a ↓ marks a letter that slipped back.

| Status | Meaning |
| --- | --- |
| Correct (green) | Independently correct at the latest scored observation. |
| Incorrect or Unsure (warm orange) | Include in targeted practice. |
| Not checked yet (neutral) | Never checked, or only skipped: insufficient assessment evidence, not automatically a weakness or a demonstrated skill. |

In mixed mode, each uppercase and lowercase form counts as a separate item.

For example, if the child identifies 20 of the 26 lowercase letters, gives incorrect responses for four, and is unsure of two, the ring shows 20 of 26 and the line below says 6 need practice (assuming all letters were assessed and saved).

A later completed check updates the recorded results for assessed letters. Skipping a letter or ending before reaching it preserves any previous result for that letter. The grid can therefore combine results from different checks; it is not necessarily a report of one complete assessment.

Tap any letter in the grid to see its history: the date, form ID and mark from every saved check that included it.

Select **View full letter results and history** to see the rest of the report and **Clear these results**. It starts folded away when the app opens.

**Struggled before** looks back over every saved check for the selected case and skill. Its **Improved** list shows letters that were Incorrect or Unsure in an earlier check and Correct since, with when they struggled and when they became correct. A letter that slips back to Incorrect or Unsure leaves the list. The letters that still need practice are already named in **At a glance**.

Skipped letters are ignored here, as in the grid. Tap a letter to see its history.

**Progress** charts how many letters were correct after each check. The chart appears from the second saved check for the selected case and skill. Below it, the list of saved checks shows each check's date, case and counts of correct, needs practice and skipped letters.

These are informal observations, not validated mastery levels, grade-level benchmarks or indicators of a reading disability.

## 6. Practice letters that need work

From **Results**, select the **Practice** button below the grid. This opens a practice deck containing only letters marked incorrect or unsure in the selected case and skill, for the selected child.

You can also select **Needs practice** directly in the Practice tab. If no letters are available, switch to **All letters** or run a letter check. Unchecked and skipped letters are not automatically included in the targeted deck.

During practice, it is appropriate to model the correct answer, provide encouragement and let the child try again. Practice does not change saved assessment results. Reassess independently later to update the deck.

### A simple at-home routine

Keep practice brief and positive. Here is one optional schedule, rather than a required or validated protocol:

| When | Activity |
| --- | --- |
| First session | Check one letter case to identify a starting point. |
| Next few days | Spend about 3–5 minutes reviewing letters that need work, along with a few familiar letters from **All letters**. |
| Later in the week | Recheck the same skill and case independently, then review the updated practice list. |

If a targeted deck is empty, celebrate the progress and periodically review familiar letters or check another skill. Stop while the activity is still enjoyable.

## 7. Saved results and privacy

Results and an unfinished check are saved in the current browser's local storage when available. You do not need to create an account or enter a child's real name.

Use the same device, browser, browser profile and website address to access existing results. On an iPad, the Home Screen app counts as its own browser: it does not share results with Safari (see [Install on the iPad Home Screen](#install-on-the-ipad-home-screen-recommended)). Another device will have its own records. There is no synchronization between devices; use **Export backup** on the Results tab to save a Backup file (for example to iCloud Drive or Files) and **Restore from backup** to bring it back. If a saved check has gone more than 30 days without a backup, the Results tab shows a reminder until you export one. Clearing website data may erase records permanently; private browsing can also make storage temporary, and Safari can delete a website's data after 7 days of use without opening it. Do not use it for official school records.

To reset a set of saved results intentionally, open **Results**, choose the correct learner, case and skill, open **View full letter results and history**, then select **Clear these results**. Read the confirmation carefully: the selected results are deleted permanently, and those letters are also removed from every saved check, so Struggled before and Progress start fresh too. The confirmation says how many saved checks are affected and their dates; use **Export backup** first if you might want them back. Mixed case includes both uppercase and lowercase for that skill.

## 8. Troubleshooting

| Problem | What to try |
| --- | --- |
| Needs practice is empty | Confirm the learner, case and Names/Sounds selection. Run a check or use All letters. |
| Save results is disabled | Mark every displayed letter, using Skip if an item was not assessed. |
| An unfinished check appears | Choose Resume check to continue, or Discard only if you no longer need the draft. |
| Results seem missing | Confirm you are using the same website address, device, browser/profile, learner and skill. On iPad, results saved in Safari do not appear in the Home Screen app (or the other way round); use Restore from backup with your latest Backup file. |
| Letters look different | Connect to the internet and reload so the Andika font can load. |
| Printing is unavailable | Copy the displayed order and form ID onto paper before beginning. |
| Local storage warning appears | Use a normal browser window that allows site storage. The app still works in memory, but results may disappear on reload. |

## A note for families and educators

Sonelire Practice is intended for informal alphabet learning at home. It is not a replacement for a standardized assessment, reading specialist evaluation or a school's required screening tools. Letter-sound scoring is parent-directed and should not be used to diagnose a reading difficulty. For ongoing concerns about reading development, discuss the child's learning needs with their teacher or a qualified reading specialist.
